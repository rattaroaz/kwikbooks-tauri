PHASE 0 — PREREQUISITES & SCOPE (COMPLETE)
--------------------------------------------------------------------------------
- [x] Define MVP scope (e.g. small business: invoicing, expenses, basic reports)
- [x] List non-goals for v1 (payroll, inventory depth, multi-currency, etc.)
- [x] Choose UI stack inside Tauri (vanilla TS, React, Vue, Svelte — pick one)
- [x] Confirm target platforms (Windows / macOS / Linux)

MVP scope (v1)
  • Single company / single books file (one SQLite DB per user data dir).
  • Chart of accounts with standard types (Asset, Liability, Equity, Income, Expense).
  • Double-entry journals; balanced posting for invoices, bills, and payments.
  • Customers and vendors (basic contact + terms metadata as needed for AR/AP).
  • Sales: invoices (line items), invoice statuses (draft → sent → paid / void).
  • Purchases: bills / expenses linked to vendors or ad hoc payees.
  • Payments: receive from customers (AR + bank/cash), pay vendors (AP + bank/cash).
  • Bank/cash accounts on the balance sheet; optional reconciliation stub only if time allows.
  • Core reports: Profit & Loss, Balance Sheet, Trial Balance, simple AR summary.
  • CSV export for reports; local-only data (no cloud sync in v1).

Non-goals for v1
  • Payroll, inventory / COGS depth, assemblies, time tracking billing.
  • Multi-currency, sales tax engines beyond simple fixed-rate line (defer advanced tax).
  • Multi-user concurrent editing, role-based permissions, server/API backend.
  • Integrated payments (Stripe, etc.), bank feeds, Plaid, live exchange rates.
  • PDF invoice designer beyond minimal print/export (can be Phase 9+).
  • Mobile apps; web deployment (desktop Tauri only for v1).

UI stack
  • React + TypeScript in the Tauri webview (official template ecosystem, component ecosystem).

Target platforms
  • Windows (primary dev on win32), macOS, Linux — ship all three via Tauri targets where feasible.
